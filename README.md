# voice-controlled-indoor-lighting
Voice-controlled lighting system for indoor farming automation.
# LUMIGARDEN
Sistema de iluminación inteligente para plantas usando:

- ESP32
- Matriz RGB WS2812B
- MIT App Inventor
- Control por voz
- Control WiFi por IP

## Funciones

- Selección de plantas  
- Modos de crecimiento  
- Floración  
- Modo nocturno  
- Control RGB automático  
- App móvil personalizada  

## Tecnologías

- ESP32
- Arduino IDE
- MIT App Inventor
- NeoPixel
